# Sicurezza / Security

**Italiano.** Se trovi un problema di sicurezza (per esempio un modo per entrare senza password o leggere la
cronologia di altri utenti), **non aprire una issue pubblica**. Contatta in privato il maintainer tramite il suo
profilo GitHub ([@BitJacker](https://github.com/BitJacker)) descrivendo il problema e come riprodurlo.
Una volta corretto, la correzione esce in una nuova versione installabile dal pulsante "Aggiorna" della pagina Admin.

**English.** If you find a security issue (for example a way to log in without a password or read other users'
history), **do not open a public issue**. Contact the maintainer privately through their GitHub profile
([@BitJacker](https://github.com/BitJacker)), describing the problem and how to reproduce it. Once fixed, the fix
ships in a new version that can be installed with the "Update" button on the Admin page.

Versione supportata: l'ultima release. / Supported version: the latest release.
